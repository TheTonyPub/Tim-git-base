# Оптимизация алгоритма Фибоначчи

## Первоначальный вариант

Сначала использовалась обычная рекурсия:

```python
if n < 2:
    return n
return fibonacci(n - 1) + fibonacci(n - 2)
```

Такой алгоритм много раз вычисляет одни и те же значения, поэтому при увеличении `n` быстро замедляется.

## Оптимизированный вариант

В основной версии используются две переменные:

```python
current, following = 0, 1
for _ in range(n):
    current, following = following, current + following
return current
```

На каждом шаге хранятся только два соседних числа Фибоначчи. Повторных рекурсивных вычислений нет.

Сложность итеративной версии — `O(n)` по времени и `O(1)` дополнительной памяти без учёта размера самих целых чисел.

Исходная рекурсивная версия сохранена в `examples/fibonacci_recursive.py` для сравнения.
