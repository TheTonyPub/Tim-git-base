# Инструкция по запуску

## Требования
- Python 3.6 или выше

## Установка
Склонируйте репозиторий и перейдите в папку с проектом:
```bash
git clone https://github.com/your-username/Tim-git-base.git
cd Tim-git-base
```

## Запуск программы
1. Откройте терминал в папке с проектом.
2. Выполните команду:
   ```bash
   python factorial.py
   ```
3. Введите число, когда программа попросит.
4. Программа выведет результат.

## Запуск тестов
Чтобы проверить, что программа работает правильно, выполните:
```bash
python tests.py
```

## Пример работы
```
Введите число: 5
Факториал числа 5 = 120
```
