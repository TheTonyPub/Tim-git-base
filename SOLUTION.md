## Запуск

Требуется Python 3.10 или новее. Дополнительные библиотеки не нужны.

```bash
python3 fibonacci.py 10
```

Результат:

```text
55
```

Аргумент должен быть неотрицательным целым числом. Нумерация начинается с нуля:
`F(0) = 0`, `F(1) = 1`.

## Тесты

```bash
python3 -m unittest -v
```

Проверяются начальные значения, `F(10)`, большое значение `F(100)`, а также
отрицательный и нецелочисленный ввод.

## Первоначальный алгоритм

Первая версия напрямую использовала рекуррентную формулу
`F(n) = F(n - 1) + F(n - 2)`. Она проста для понимания, но многократно
вычисляет одни и те же значения.

- время: `O(2^n)`;
- дополнительная память: `O(n)` из-за стека рекурсии.

## Оптимизация

Итоговая версия последовательно вычисляет числа и хранит только два последних
значения. Рекурсия и повторные вычисления устранены.

- время: `O(n)`;
- дополнительная память: `O(1)`.

Например, `F(100)` вычисляется сразу, тогда как наивная рекурсивная версия
потребовала бы практически неприемлемого количества вызовов функций.
