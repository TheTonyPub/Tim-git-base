# Вычисление факториала

Программа вычисляет факториал неотрицательного целого числа.

## Запуск

Для запуска программы выполните:

```bash
py app.py
```

После запуска введите целое неотрицательное число.

Пример:

```text
Введите n: 5
5! = 120
```

## Оптимизация

Первоначальная версия программы использовала рекурсивный алгоритм вычисления факториала.

В улучшенной версии рекурсия была заменена на итеративный алгоритм с использованием цикла `for`.

Оба алгоритма имеют сложность O(n) по времени. Однако рекурсивная версия использует O(n) дополнительной памяти из-за стека вызовов, а итеративная версия использует O(1) дополнительной памяти.

Итеративная версия также не зависит от ограничения глубины рекурсии Python, поэтому лучше подходит для больших значений `n`.
