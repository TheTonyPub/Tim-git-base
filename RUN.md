# Числа Фибоначчи

Автор: Леонов Никита Олегович, группа 15-25.

Программа вычисляет N-е число Фибоначчи, где `F(0) = 0`, `F(1) = 1`.

## Запуск

Требуется Python 3. Внешние библиотеки не нужны.

```bash
python fibonacci.py 10
```

Результат:

```text
55
```

## Проверка

Тесты можно запустить командой:

```bash
python -m unittest discover -s tests -v
```
