# Числа Фибоначчи

Автор: Леонов Никита Олегович, группа 15-25.

Программа вычисляет число Фибоначчи по его индексу: `F(0) = 0`, `F(1) = 1`,
`F(n) = F(n - 1) + F(n - 2)`. Индекс — целое неотрицательное число.

## Запуск

Нужен Python 3.8 или новее. Внешних зависимостей нет. Команды выполняются из
корня репозитория; в Windows вместо `python` можно использовать `py`.

```bash
python fibonacci.py 10
```

Результат: `55`. Примеры граничных значений:

```bash
python fibonacci.py 0
python fibonacci.py 1
```

Результаты: `0` и `1` соответственно. Отрицательный индекс, дробь, текст или
отсутствующий аргумент вызывают понятную ошибку ввода и код завершения `2`.
Справка: `python fibonacci.py --help`.

## Проверка

```bash
python -m unittest discover -s tests -v
```

Проверяются известные значения, границы `0` и `1`, `F(100)`, совпадение с
первоначальным алгоритмом для небольших индексов, неверные аргументы функции,
успешный запуск из командной строки и обработка ошибок ввода.

## Оптимизация и сравнение

Основная программа использует цикл и два накопителя. Первоначальная рекурсия
сохранена в [examples/fibonacci_recursive.py](examples/fibonacci_recursive.py)
и доступна отдельной командой:

```bash
python examples/fibonacci_recursive.py 10
python benchmark.py
```

Для рекурсивной версии используйте небольшие индексы: количество вызовов
растёт экспоненциально. Объяснение изменения, оценки сложности и методика
замера находятся в [OPTIMIZATION.md](OPTIMIZATION.md).
